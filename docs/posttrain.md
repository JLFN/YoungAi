## 0. 三句话

1. **用户视角一个字不变**: 上传一份 jsonl(`messages` 或 `text` 两种行, 与 Unsloth 一一对应) → 点"开始训练" → 训完在聊天页用开关挂/卸。
   没有新文件格式, 没有新字段, 没有"扩展题"要人写。
2. **训练器内部从一步变两步**: 步 1 记忆(现在的训练, 不动) → 步 2 泛化(模型自己答扩展题, 带材料的自己当教师, 逐 token 对齐)。
   两步在同一轮里, 同一份料, 同一个损失核。
3. **判决从一个数变三个数**: 记忆(原形式留出损失) / 泛化(**另一种形式**的留出损失 + 生成答对) / 局部性(保持料 KL + wt2 五指标, 已有)。
   泛化那个数今天没有, 所以今天看不见"记住了但换种说法不会"这个病。

## 1. 为什么现在只会背, 不会举一反三

盘上两条证据(10-10 夜 / 10-11):
- `youngai_facts.jsonl` 12 条事实 × 3 种问法, 训 3 轮: 留出损失 −51%, 但换一种新措辞的 13 道题只答到 8 道, 4 道编。
- 一段代码教会了(同语言复述全对), 换一种语言写同一个算法就不行。

一句话原因: **权重更新只沿训练信号里"共有"的方向走。** ③ 是挂在每层 MoE 输出上的低秩项 `y += xn·B·A`。
只给一种形式的料, 损失最便宜的下降方向就是"看到这种 xn 就补这串 token"; 另一种语言的 xn 根本不点火。
同一个算法用 4 种语言写、再用中英文各讲一遍原理, 这 6 份料唯一的共同点是算法本身(底座中间层本来就有的跨语言表征), 梯度才被逼进那个共享子空间。

现在的留出(题去空白 FNV 五取一)留的是**同一形式**的另一道题, 量的是记忆, 量不到泛化。所以 −51% 和换语言挂科并存, 尺本身看不见病。

## 2. 方案: 一轮两步三指标

### 2.1 一轮里发生什么

```
jsonl ──┬─ 步 1 记忆(现状不动) ──────────────────────────────┐
        │   带 context 的题: 教师 = ①+② 读材料答题, 学生 = ①+②+③ 不看材料 │  同一个
        │   不带的题 / text 段: 目标 = 答案 token 本身(one-hot)              │  余量桶 KL
        │                                                                      │  损失核
        └─ 步 2 泛化(新增) ─────────────────────────────────────┤
            ① 学生(①+②+③, 不看材料)对每道训练题**自己采样 N 份答案**      │
            ② 教师(①+② + 材料在上下文)给每份采样答案逐 token 打 top-K 分布   │
            ③ 学生在**自己采出来的那串 token** 上逼近教师 ─────────────────┘
            ④ 原料里那条金标答案照步 1 的方式再算一次(金标分支)
轮末: 三个指标 + 探针原样 + ckpt_eNN
```

- **步 2 的教师怎么来**: 带 `context` 的题, 材料就是 context; 不带 context 的 `messages` 题, 把这条 (问, 答) 本身当示范放进教师上下文
  (SDFT 的做法), 教师照样是"看过答案的自己"。`text` 段不进步 2(没有问句, 采样没有可比的东西)。
- **多样性从哪来**: 学生自己采样(温 1, 模型卡配方)。不要人写扩展题, 不要训练器外的出题步——10-10 删"出题"删对了, 删的是让用户先出题那一步。
- **为什么顺序是先记后泛, 不能反、不能跳**(文献数字):
  - 对模型完全不知道的新事实, 纯 on-policy 蒸馏 31% < SFT 46%(2607.11020): 新东西先 off-policy 灌进去, 采样才采得出来;
  - 跳过记忆步只做采样那一步 → 1.8%(崩); 记忆 + 多样料但只做 SFT → 14%; 两步全上 → 35%(GRIN 2608.25243, Qwen3-4B, 推理类题);
  - 知识先稳再叠技能 44.6%, 反序 30.3% 低于基线(2601.11258)。
- **金标分支为什么要留**: 采样全错时 on-policy 一侧没有梯度(模型不会的东西采不出来), 金标那行保证总有信号(GRIN 的 Golden 项, 无重要性比)。
  实现上就是步 1 本身, 不是新东西。
- **损失方向**: 现有核是教师 top-K + 余量桶的 KL(前向)。SDFT 用反向 KL, RL's Razor 说 on-policy 挑的是对底座 KL 最小的解。
  先沿用现有方向把链跑通, 方向当作一个开关留给探针【无数据·待实测】。

### 2.2 三个指标(全部按轮打印, 选轮规则不变: 过门的轮里泛化损失最低)

| 指标 | 量什么 | 怎么算 | 现状 |
|---|---|---|---|
| 记忆 | 原形式记住没 | 现有留出(同形式 FNV 五取一)的答案位损失 | 已有 |
| **泛化** | 换形式会不会 | `eval=` 指定的**整组留出**(留一种语言 / 一种措辞组)的答案位损失 + 贪心生成原样 | **没有, 本方案核心** |
| 局部性 | 别的有没有被带歪 | 保持料 KL(hold.jsonl, 教师 = 不看材料的自己)+ wt2 五指标门 | 已有; 文献说它就是遗忘的预测器 |

泛化留出为什么要用户给一个文件而不是训练器自己切: 训练器不知道哪些行是"同一件事的另一种形式"。Unsloth 同样是 `eval_dataset` 单独一份。
不给 `eval=` 时泛化那栏打"未提供", 选轮退回记忆留出(= 今天的行为), 不报错。

### 2.3 用户看到的差别(全部)

- 训练页: 多一个可选的"留出文件"下拉(同一个语料目录里的另一份 jsonl)。不给也能训。
- 记录页: 轮次表多一列"泛化留出"; 探针原文多一组(留出形式的题: 部署态 / 挂 ③ / 参考答案并排)。
- 训练用时: 步 2 每题多 N 份采样 + N 次教师打分【无数据·待实测, 先量再报】。

## 5. 料从哪来: 边界外的东西只能从环境拿

语料再好也只把文本里有的搬进权重: ③ 的边界 = 底座 ∪ 语料。出边界的信号只有一种来源 —— **环境反馈**(代码跑没跑通、测试过没过、第二天行情、用户说"错了"),
它不在任何语料里。机制 = 探索(采样把既有零件做新组合) × 外部判官 × 固化(验证过的轨迹蒸馏回权重)。没有外部判官的自蒸馏只能重排已有的东西。

落到本仓:
- **agent 轨迹自动落 jsonl**: ds4-agent 一道题跑完、结果验证过(测试通过 / 用户没纠正), 这一段自动写成一行 `{"messages":[问, 答], "context": 工具输出}`
  到语料目录。用户不手写料, 料是干活时攒的。【未做, 本方案之后的一步】
- **判官住 agent / 工具那一侧**(执行、测试、结算), 训练器只认 jsonl —— 训练器保持通用, 不再往定制化场景跑。
- **"知道自己在边界上"**: 学生(不看材料)与教师(看材料)分歧大、或 N 份采样互相不一致, 就是"不知道"的信号; 这时 agent 该去动手(跑 / 查 / 问), 不是硬答。
  这个信号步 2 顺手就有(采样分歧), 怎么接进 agent 另立方案。
