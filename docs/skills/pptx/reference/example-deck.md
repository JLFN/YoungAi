## 本季度三件事

- 个人助理: 文件、网页、文档产出, 每一步在沙盒里
- 云手机: 助理能在一部虚拟安卓手机上点、滑、打字
- 后训练: 一条命令, 自己的料训进自己的模型

## 助理: 一句话进来, 文件交出去

- 文件读写、网页检索、Word / Excel / PPT / PDF 直接生成
- 每次动手都在内核沙盒里: 没有网络, 只能写工作区
- 越界先问你: 工作区以外的写、联网外送都要点头

## 云手机: 模型自己操作 app

- 虚拟安卓 13, 按宿主可用内存定上限, 最低 2 GB
- 每个动作带回新一帧截图和元素表
- 中文输入走剪贴板粘贴, 不装输入法

<!-- 这一页如果有时间可以放实况视频。 -->

## 后训练: 料只有两种, 训练只有一条命令

- messages 或 text 两种 jsonl, 和主流训练器一致
- 选轮规则: 留出损失比第 0 步低, 且收口不少于部署态
- 训完不自动挂, 开关打开才挂

<!-- 强调"训完不自动挂"是用户定的规矩。 -->
