# 做一份 PPT

这台机器上出 .pptx 只有一条路: `write_document`, 路径以 .pptx 结尾, 内容用 Markdown 写, 一行 `---` 开始新的一页。
不用找别的程序, 不用装任何库; 版式(字体、间距、页码)是内置的, 你只管内容。

## 先想清楚再动手

1. 一句话写下这份 PPT 要让听众相信什么(结论)。整份片子都为它服务。
2. 定听众和场合: 汇报给领导 / 对外路演 / 内部培训 / 课堂讲解, 决定语气和细节深浅。
3. 定页数: 5 分钟 5~7 页, 15 分钟 10~15 页, 30 分钟不超过 25 页。一页只讲一件事。
4. 列大纲(每页一行标题), 再往每页填内容。大纲不顺, 先改大纲。

## 每一页怎么写

- **第一页 = 封面**: 只有一个一级标题和一行副标题(谁 / 日期 / 场合)。写出来就是"一个标题 + 一行字", 它会被排成封面版式。
- **第二页 = 要点或目录**: 3~5 条, 告诉听众接下来会讲什么。
- **正文页**: 标题是一句有观点的话(写"成本比去年降 18%", 不写"成本情况"); 正文 3~5 条要点, 每条不超过两行; 数字用表格; 能画成表的不写成段落。
- **数据页**: 用 Markdown 表格, 最多 5 列 8 行; 表上面一行字说这张表证明了什么。
- **图片页**: 用户给了图(在工作区 inbox/ 里)就用 ![说明](inbox/图名.png); 一页一张图加一两句话, 图放右边文字放左边是自动的。
- **最后一页 = 结论 / 下一步 / 请求**: 把第一步写的那句话放回来, 加上希望听众做什么。
- **讲稿**: 每页末尾用一段 HTML 注释写讲稿(30~80 字), 它会进"演讲者备注", 放映时听众看不到。

## 风格(theme): 用户说了样子就一定要选

`write_document` 的 theme 参数定整份片子的底色、强调色和装饰, 只有三种, 别的名字会报错:

| 用户的话 | theme | 长什么样 |
|---|---|---|
| 科技风 / 科技感 / AI / 产品发布 / 酷一点 / 深色 / 现代 | tech | 深海军蓝底, 青色强调条和圆弧, 浅色字 |
| 温暖 / 生活 / 教育 / 餐饮 / 亲切 | warm | 米白底, 橙色强调 |
| 没说, 或要"简洁""商务""正式" | clean | 白底, 深蓝标题, 没有装饰 |

用户点名要某种风格时, 不许留在 clean。要"更炫"的效果不在 theme 里的, 如实说明只有这三种。

## 写法上的规矩

- 全篇用用户这条消息的语言; 标题不超过 20 个字; 不写"谢谢观看"页。
- 一级标题只给封面; 每一页第一个标题就是这页的标题, 用二级标题。
- 要点用 - 开头, 最多两级; 不要在一页里塞超过 6 条。
- 加粗只用在真正要强调的数字或结论上, 一页最多两处。
- 用户没给图就不要编图片路径(路径不存在会出错)。

## 交出去

1. 内容全部写好后, 一次调用 `write_document` 出 .pptx(不要先写 .md 再转, 多一轮没有意义; 除非用户要改第二版, 那时从工作区里已有的 .md 用 source 参数转)。
2. 结果里有页数和大小; 页数和大纲对不上就查哪页漏了 `---`。
3. 用 share 把文件交给用户, 并用两三句话说明这份片子的结构和建议的讲法。
