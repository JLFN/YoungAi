# 工作台装成手机 App(PWA)

工作台页面(`./ds4-train` 的 `GET /`, 文件 `web/studio.html`)是一个 PWA: 手机浏览器打开后可以"添加到主屏幕",
之后像 App 一样全屏打开、有自己的图标, 不再有浏览器地址栏。

## 怎么装

| 设备 | 操作 |
|---|---|
| 安卓 Chrome | 打开工作台 → 底栏"更多" → "安装到主屏幕"(或浏览器菜单里的"安装应用") |
| iPhone / iPad Safari | 打开工作台 → 底部"分享"按钮 → "添加到主屏幕" |
| 电脑 Chrome / Edge | 地址栏右侧的"安装"图标 |

**前提: 页面必须是 https 打开的, 或者就是本机地址(`localhost` / `127.0.0.1`)。**
这是浏览器的规定, 不是我们的: 不满足时 service worker(说白了就是浏览器替网页常驻的一段后台脚本, 管离线缓存)注册不上,
安卓 Chrome 不给"安装"按钮。这时"更多"页里会直接写"现在是 http 打开的"。页面本身照常能用, 只是装不成 App。

手机用 `http://192.168.x.x:8000` 这种局域网地址打开就属于这种情况。要装, 给工作台套一层 https。工作台自带一条路(下一节"从互联网访问");
也可以用 Tailscale(`tailscale serve --bg 8000`, 手机用 `https://<机器名>.<tailnet>.ts.net` 打开)或自己的反向代理, 只要给手机的是 https 地址、后端转到 `127.0.0.1:8000`。

## 从互联网访问(设置 → 穿透 + 证书)

要一台有公网 IP 的云服务器(Linux, 有 systemd, 能用密码 SSH 登录)和一个解析到它的域名证书。都在工作台里点, 不用登服务器:

1. 左侧栏最底下(手机上: "更多" → "设置")点**设置**, 填云服务器的公网 IP、SSH 端口、用户名、密码, 保存。
   **公网端口**留空就是默认(有证书 443, 没证书用页面端口 8000)。两种情况要改成别的(比如 8443): 服务器上 443 已经被 nginx 之类占着;
   服务器在大陆且域名没备案 —— 云厂商会拦 80/443(https 也拦), 别的端口一般不拦。PWA 只要求 https, 不要求 443, 地址变成 `https://<域名>:8443/` 照样能装。
   穿透开着时改公网端口会自动重新部署。
2. 去云厂商控制台 → 安全组 → 入方向, 放行**公网端口**(默认 443)。SSH 端口本来就开着; 别的口都不用开。这一步只能你自己点, 工作台 SSH 进去也改不了安全组。
3. 打开**穿透**开关。第一次约半分钟, 弹窗里一步步亮: 连服务器 → 下载 frp → 上传 → 启动 frps → 建 SSH 通道 → 启动 frpc → 检查公网端口。
4. **上传证书压缩包**: 阿里云 / 腾讯云下载的证书 zip 直接传(包里有 Nginx/Apache/IIS 好几套也没关系, 自动挑 PEM 格式、带中间证书、和私钥配对的那套)。
   公网地址变成 `https://<你的域名>/`, 手机打开就能"添加到主屏幕"。

背后是什么: 本机 `ds4-train` 拉起 frp 客户端(frpc), 经云服务器上的 frp 服务端(frps)把公网口转回本机页面端口。
frpc 和 frps 之间的控制通道套在一条 `ssh -L` 端口转发里, frps 的控制口只听服务器本机 —— 所以安全组只要 SSH + 公网端口; ssh 断了(断网、服务器重启)自动重连。
TLS 在本机由 frpc 解开, 证书私钥不离开这台机器。公网上照样要登录; 外部程序调 `/v1` 照样要 API 密钥。

服务器上已经有东西时(开穿透第一步会 SSH 进去看一遍谁占着哪个端口):

| 服务器现状 | 工作台怎么做 |
|---|---|
| 什么都没有 | 装 frps(systemd 服务 `ds4-frps`, 服务器重启自己起来), 控制口 7000 |
| 已经有一个 frps(别的项目在用), 令牌认证、放行我们的公网端口 | **直接复用**, 服务器上什么都不装(弹窗写"复用已有 frps") |
| 有 frps 但不能复用(放行端口里没有我们的公网端口 / 配置读不到 / 不是令牌认证), 或 7000 被别的程序占着 | 另装 `ds4-frps`, 控制口换成 7001 起的空口。走 SSH 通道, 不用动安全组 |
| 公网端口被别的程序占着(常见: nginx 占 443) | 不动它, 直接报"公网端口 xxx 被 nginx 占着", 设置里换个公网端口 |

| 出错提示 | 实际原因 | 怎么办 |
|---|---|---|
| 连不上服务器的公网端口 443 | 安全组没放行(最常见) | 放行 TCP 443(或你设的公网端口) |
| 服务器关了 SSH 端口转发 | sshd_config 里 `AllowTcpForwarding no` | 改成 yes, 重启 sshd |
| 公网端口被占用或不许用 | 服务器上别的程序占着这个口(常见是 nginx 占 443) | 设置里换个公网端口 |
| 显示已连通, 手机却打不开 | 大陆服务器 + 域名没备案, 云厂商拦了 80/443 | 公网端口换成 8443 之类, 或去备案 |
| 本机域名解析到 198.18.x.x | 本机开着 Clash 之类的假 IP 模式, 不代表公网解析错了 | 用手机流量打开验证 |
| SSH 登录被拒 | 密码不对, 或服务器关了密码登录 | 服务器 `/etc/ssh/sshd_config` 里 `PasswordAuthentication yes` |
| 服务器的 SSH 指纹变了 | 服务器重装过系统 | 确认是自己的服务器后删 `~/.ds4/studio/known_hosts` |
| 下载 frp 失败 | 工作台这台机器连不上 GitHub(国内常见; 主进程没带代理) | 在能上 GitHub 的机器下官方包([frp v0.71.0](https://github.com/fatedier/frp/releases/tag/v0.71.0)), 按 `frp_sha256_checksums.txt` 校验后, 把 frpc / frps 放进 `~/.ds4/studio/frp/0.71.0/linux_<架构>/`(本机的 frpc 一份, 服务器架构的 frps 一份) |
| 证书和私钥不是一对 | 私钥是另一张证书的 | 重新下载同一次申请的证书包 |
| 域名解析到的不是这台云服务器(黄字) | 域名 A 记录没指向它 | 去域名解析加 A 记录; 只是提醒, 穿透本身是通的 |

盘上都在 `~/.ds4/studio/`: `cloud`(服务器账号, 0600; 密码要给 ssh 用所以是可还原地存, 靠文件权限护住, 页面拿不回原文)、
`frp/`(frp 二进制、frpc.toml、frpc.log、SSH 通道日志 sshfwd.log、部署日志 deploy.log, 都 0600; cloud 里的 `pub` 行就是公网端口, 0 = 默认)、`tls/`(证书)。关掉穿透只停本机 frpc, 服务器上的 frps 留着(不占公网口)。
端到端测试: `tests/net/tunnel_e2e.sh <服务器IP> <用户> <密码>`(从零起一个测试工作台跑全套; 没有云服务器时可用 OrbStack 起一台 Ubuntu, 用法见脚本头)。
对正在跑的工作台重开一次穿透看每一步: `tests/net/tunnel_try.sh <工作台用户名> <密码>`。

## 手机上的布局

同一个网址, 页面按打开它的环境选布局(`<html data-shell>`, 规则在 `web/studio.html` 的 `<head>`):

- **app 布局**: 触屏设备(或装成 App 后的独立窗口)且窗口窄于 900 px —— 手机竖屏/横屏、iPad 竖屏。
  顶栏 + 底部四格(助理 / 模型 / 训练 / 更多); 对话列表在左上角菜单打开的抽屉里; 表格变卡片; 训练页分"进度 / 设置"两段。
- **电脑布局**: 其余情况(电脑浏览器窗口拉多窄都算, iPad 横屏), 即原来的左右布局。

在电脑上看手机布局: 网址后面加 `?shell=app`(`?shell=desk` 反过来)。

## 缓存与更新

`web/sw.js` 只缓存页面外壳(页面本身、图标、manifest), **不缓存任何数据接口**(`/api` `/v1` `/metrics`):

- 页面是网络优先: 改了 `web/studio.html`, 手机上刷新(或关掉 App 再开)就是新版, 不会被旧缓存卡住。
- 断网时打开 App 会显示缓存的外壳, 引擎卡片显示"连不上", 而不是一张白屏。
- 改了 `sw.js` 里的缓存清单, 要把 `CACHE` 的版本号 +1, 否则老手机上的旧缓存不会被清掉。
